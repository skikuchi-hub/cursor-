# 写真チェックの教訓（見間違いの再発防止）

毎日の写真チェック（docs/PHOTO_CHECK_ROUTINE_PROMPT.md）が **判定の前に必ず読む** ファイル。
担当者がアプリの「⚠ 要確認」で **「入力は合っている（AI の見間違い）」** を押した事例を、ルーティンが分析してここに残す。
「ルール」はこのファイルの中では新しいものほど下。手順書の判定ルールより優先する。

## ルール（判定の前に守ること）

1. 補充前と補充後が同じ写真でも、記録に補充・入れ替えが無ければ入力ミスではない（何も変えなかった訪問は同じ写真を上げる運用。2026-11-09 石原さん）。
2. 「空き枠が残っている」「陳列スコアが低い」「POP が無い」「カプセルが少ない」は所見に書くだけ。inputIssue は false（本人に通知しない）。
3. BOX 機で「取られた（out）」の枠に補充前の写真で景品が残って見えるときは、扉のガラスの反射や奥の背景の絵を景品と見間違えていないか拡大して確かめてから inputIssue を付ける。確信がなければ false。
4. 景品名は記録の名前をそのまま使う。見た目の呼び名（「白いぬいぐるみ」等）と記録の名前が違うだけで「別物」と判定しない。同じ物か迷ったら前回の補充後写真の同じ部屋と見比べる。
5. 4 人機の部屋の中身が「記録の景品名と違う」と言うのは、POP・景品の両方で別キャラだと確認できたときだけ。
6. BOX 機で「取られた（out）」の枠に補充前の写真で景品が残って見えても、その訪問で同じ枠に別の景品を入れている（out かつ filled が別物）なら、訪問中にお客さんが取って入れ替えた可能性が高い。inputIssue は false にして所見に残す（2026-11-20 下山門 カリーノIII 12 番、石原さん「入力は合っている」）。
8. **景品名は必ず全文で読む。** 分析用のスクリプトで名前を切り詰めて表示しない（14 文字で切ると「ミニミニChibiぬいぐるみマスコット・アンパンマン」が「ミニミニChibi」に見える）。「ミニミニChibiぬいぐるみマスコット」は たまごっち／サンリオ／アンパンマン のシリーズ名で、アンパンマンのマスコットは正しくその名前。記録名と写真が違うと言う前に、記録名の末尾まで確認する（2026-11-18〜24 東平尾 4人機② C、柳瀬さん「入力は合っている」。通知 1 回分を無駄にした）。
9. **景品名は「写真と合っているか」と「景品マスタにあるか」は別。** 写真と合っていても、記録の名前が景品マスタ（タブ「景品マスタ」）に無い名前だと、その補充・払出はマスタの在庫に反映されない。マスタに無い名前を見つけたら inputIssue は付けず、日次の報告で菊地さんに「マスタの名前にそろえるか」を聞く。菊地さんが「本人に直してもらう」と言ったときだけ、その記録の写真に inputIssue=true・ask（マスタの名前と直し方）を付けた JSON を出す（2026-11-26 東平尾 4人機② C：「ミニミニChibiぬいぐるみマスコット・アンパンマン」は写真どおりだがマスタに無く、マスタの「アンパンマン」に変更を依頼）。補充・入れ替えで入れた景品の名前を直す依頼は ask に「入れた景品」と書く（アプリが名前ボタンではなく入れ替えの行を光らせる）。
7. 別の機械・別の店の写真が付いているだけの訪問は、記録の数字（売上・払出・補充）のミスではない。inputIssue は false。所見に書き、日次の報告で菊地さんに伝えるだけ（2026-11-12 下山門 ミニSP、石原さん「入力は合っている」）。
